# Network Toolkit

This repository contains the sales website for **Network Toolkit.exe**, a standalone Windows application for network monitoring, diagnostics, and security checks. The website presents the product, its features, license options, payment methods, and contact information.

> This repository contains the website source code. It does not include the Network Toolkit.exe application. Contact the developer to purchase the software.

## Product

Network Toolkit is designed for IT professionals, administrators, and users who want network tools in one desktop application. The advertised app supports Windows 10 and Windows 11 and runs as a standalone executable without requiring a Python installation.

Highlights include:

- Live bandwidth graphs and network quality ratings for gaming, video calls, and streaming
- Continuous traceroute with per-hop latency and packet-loss monitoring
- LAN device discovery with IP, MAC address, and manufacturer information
- TLS certificate inspection, VPN detection, and DNS leak testing
- Wi-Fi channel charts, multi-ping monitoring, speed tests, and TCP health metrics
- Local REST API and Discord or Slack webhooks for integrations and alerts
- Local history and settings storage using SQLite
