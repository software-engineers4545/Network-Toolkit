Real-Time Monitoring

See exactly what your network is doing.

Stop guessing if your internet is fast enough. Our heuristic algorithm analyzes your latency, jitter, packet loss, and bandwidth to give you instant, color-coded ratings.

  • Gaming Quality: Needs <40ms ping and low jitter.
  • Video Call Quality: Needs stable ping <100ms.
  • Streaming Quality: Bandwidth-focused for 4K.
  • Auto-scale live bandwidth graphs.
Deep Diagnostics

Pinpoint network drops instantly.

Standard traceroute only runs once. Our Continuous Traceroute pings every single hop every 5 seconds, showing you the exact router where your connection is dying.

  • Updates every 5 seconds automatically.
  • Shows Current, Average, and Worst RTT per hop.
  • Geolocates the IP of every hop.
  • Detects packet loss on specific routers.
Security & Privacy

Know who is on your Wi-Fi.

Run a parallel ping sweep of your entire /24 subnet. We cross-reference MAC addresses with a built-in OUI database to tell you exactly what devices are connected.

  • Find hidden devices instantly.
  • Inspect SSL/TLS certificates of active connections.
  • Detect DNS leaks to protect your privacy.
  • TCP Health tab to spot bad cables/Wi-Fi interference.

Frequently Asked Questions

Do I need Python installed to run the .exe?
No. The Standard License comes as a completely standalone Network Toolkit.exe file. You can copy it to any Windows 10 or 11 PC, and it will run instantly without requiring any terminal commands or Python installation.
Can I use this on multiple computers?
The Standard License is for a single user on a single PC. If you are an IT agency or need to deploy it across an office, please contact us for bulk licensing or the Source Code option.
Does the app collect my data?
Absolutely not. Privacy is our priority. All data (including your history graphs and settings) is stored locally on your machine in a SQLite database. The only external requests made are to public APIs to check your Public IP and GeoIP location.
What is the REST API used for?
The REST API allows you to pull your live network stats into other software like Home Assistant, Grafana, or custom dashboards. It runs locally on http://127.0.0.1:8080.
